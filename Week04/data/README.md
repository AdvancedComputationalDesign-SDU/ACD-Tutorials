# Week 04 data

This folder contains the input files for numerical comparison and text processing:
an illustrative measurement table and a literary text. Keep these source files
unchanged so repeated runs can use the same inputs.

[beam_measurements.xlsx](beam_measurements.xlsx) contains illustrative beam measurements used in the
lecture and tutorials:

| Column | Meaning | Unit |
|---|---|---|
| `x_m` | Position along the beam | Meters |
| `a_mm` | Deflection for case A | Millimeters |
| `b_mm` | Deflection for case B | Millimeters |

Deflection is positive downward. These values are for practicing data handling
and visualization; they are not measurements from a physical experiment.

[alice_in_wonderland.txt](alice_in_wonderland.txt) contains Lewis Carroll's *Alice's Adventures in
Wonderland* and is used in the optional word-count example.

Keep the supplied inputs unchanged. Save derived results in this week's
`outputs/` folder.
