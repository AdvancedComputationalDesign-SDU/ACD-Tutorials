# Week 05 data

This folder contains the shared photographic input for the image-processing
examples, allowing different filters to be compared on the same source image.

[Lenna.png](Lenna.png) is the 512 × 512 RGB image used in the lecture and image-processing
examples. Use it to compare how filters affect the same input.

The RGB composition tutorial generates its image numerically and does not
require an input photograph.

Keep the supplied image unchanged. Save derived results in this week's
`outputs/` folder.
